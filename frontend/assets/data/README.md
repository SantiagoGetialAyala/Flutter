# Municipios de Colombia

Fuente: DANE, catálogo DIVIPOLA publicado en Datos Abiertos Colombia.
https://www.datos.gov.co/Mapas-Nacionales/DIVIPOLA-C-digos-municipios/gdxc-w37w

Consulta: https://www.datos.gov.co/resource/gdxc-w37w.json?$limit=2000
Descargado el 6 de noviembre de 2026. El catálogo indica corte de diciembre de 2024.
Contiene 1122 registros con departamento, municipio/área no municipalizada y
coordenadas de referencia. Estas coordenadas solo centran el mapa: el usuario
debe marcar la ubicación real de su finca. El archivo local evita peticiones
externas y conserva el formulario cuando no hay conexión.
